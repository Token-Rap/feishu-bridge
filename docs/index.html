Capabilities

让每个实例各司其职。

共享代码，分开运行状态；从飞书发起交互，接续已有工作。

01 / ISOLATION

多实例 home

每个 bot 拥有独立的配置、运行状态和绑定工作目录。

02 / CONTEXT

会话续接

持久化会话信息，支持续接与会话管理。

03 / STREAMING

流式卡片

通过飞书消息与流式卡片返回 agent 的输出。

04 / OPERATIONS

fleet_admin / fleet_ctl

查看和管理实例配置，或手动控制实例进程。

05 / HEALTH

watchdog

检查心跳和卡住的回合；恢复能力依赖相应配置。

Architecture / Role mapping

从角色理解协作。

借鉴 DeepSeek Super-agent 的角色与控制回路，对照本项目的实例和入口。

Router

fleet-manager / fleet_admin

fleet-manager 负责协调与分派约定；fleet_admin 管理实例及配置。

Workers

领域 bot

各领域 bot 在自己的 home、会话和工作目录中执行任务。

Trigger

飞书消息与事件

消息和群事件提供交互入口，具体处理取决于配置和代码。

Watchdog

fleet_watchdog

外部控制回路检查健康状态；恢复依赖 macOS launchd 服务。

角色是工作约定：公开示例中任务和结果由人转交，并不提供开箱即用的跨 bot 自动分派或结果回传。
